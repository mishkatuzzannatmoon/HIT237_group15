# NT Wildlife Recording System

## Project Overview

A Django-based web application developed for recording and managing wildlife audio recordings in the Northern Territory. The system allows users to upload wildlife recordings, manage species information, flag anomalies, and search/filter recordings efficiently.

## Features

- User registration and login/logout authentication
- Upload wildlife recordings with audio files
- Species management system
- Recording detail and list pages
- Filter and search functionality
- Confidence score tracking
- Anomaly flagging system
- Service layer architecture
- Class-based views (CBV)
- Exception handling
- Responsive user interface

## Installation & Setup

1. Clone the repository
2. Create virtual environment
3. Install requirements.txt
4. Run migrations
5. Start server

## Commands:

1. pip install -r requirements.txt
2. python manage.py migrate
3. python manage.py runserver
